# HR Management Application

This project is a comprehensive Human Resources (HR) management application designed to streamline and simplify HR operations for businesses. It provides a centralized platform for managing employee data, recruitment, attendance, payroll, and more.

## 1. Idea Selection

The core concept is an all-in-one HR mobile-first application tailored for small to medium-sized businesses (SMBs). Many existing HR solutions are either too complex or too expensive for this market segment. 

Our application aims to fill this gap by providing a powerful, yet intuitive and affordable, solution that covers the entire employee lifecycle. The key competitive advantages are:
- **Mobile-First Design:** Allowing HR managers and employees to perform tasks on the go.
- **User-Centric Interface:** Focusing on simplicity and ease of use to reduce training time.
- **Integrated Modules:** Combining recruitment, employee management, attendance, and payroll into a single, seamless experience.
- **Scalability:** Built to grow with the business, from a handful of employees to a larger workforce.

## 3. App Requirements

### Functional Requirements:

- **User Authentication:** Secure login for HR personnel to access the dashboard.
- **Dashboard:** A central hub providing an at-a-glance overview of key HR metrics (e.g., total employees, open positions).
- **Employee Management:** Create, view, update, and delete employee profiles. Store personal and professional information.
- **Recruitment Management:** Post and manage job openings. Track applications through various stages (e.g., received, reviewed, interviewed).
- **Public Job Board:** A public-facing page where external candidates can view and apply for open positions.
- **Attendance Tracking:** Monitor employee attendance, including clock-in/out times, late arrivals, and absences.
- **Payroll Management:** View and manage employee payroll details, including earnings, deductions, and payment history.
- **Notifications:** A system to alert HR staff about important events like new applications or leave requests.
- **Reporting & Analytics:** Generate and view reports on key metrics like employee turnover and hiring trends.

### Non-Functional Requirements:

- **Performance:** The application must be fast and responsive, with page load times under 2 seconds.
- **Security:** All sensitive employee data must be encrypted and stored securely. Access controls must be in place to ensure users can only see data they are authorized to view.
- **Usability:** The interface must be intuitive and easy to navigate for non-technical users.
- **Reliability:** The application should have high availability (99.9% uptime).
- **Scalability:** The system should be able to handle a growing number of employees and job applications without degradation in performance.
- **Responsiveness:** The user interface must adapt seamlessly to various screen sizes, from mobile phones to desktop monitors.

## 4. Prototype Evaluation

A user evaluation was conducted on the high-fidelity prototype to assess its usability and effectiveness.

- **Technique Used:** Heuristic Evaluation & User Task Analysis. A small group of target users (HR managers from small businesses) were given a set of common tasks to complete, such as "Add a new job posting," "Review an application for the Senior Engineer role," and "Find the payroll details for Sarah Johnson."
- **Findings:**
  - **Positive Feedback:** Users found the overall navigation to be intuitive and clean. The dashboard was praised for providing a clear and useful summary of HR activities. The separation of the public job board and the internal HR dashboard was clear.
  - **Areas for Improvement:**
    - Some users initially had trouble finding the "Add New Job" button, suggesting it could be more prominent on the recruitment page.
    - The filtering options on the employee and application lists were helpful, but users requested the ability to filter by more criteria (e.g., 'start date' for employees).
    - During the application submission process, a user noted that there was no confirmation message after uploading a resume, causing temporary confusion.
- **Conclusion:** The evaluation confirmed that the core workflows are logical and easy to follow. The feedback provided actionable insights for minor UI/UX enhancements to improve clarity and user satisfaction. The prototype was deemed a strong foundation for the final product.
